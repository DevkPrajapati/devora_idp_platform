How to use this PDF

  • Print it, or keep it on a second screen / phone.
  • Green box = speak these words.
  • Blue box = click with the mouse.
  • Orange box = type this exact value.
  • Do not read the Hindi lines. They are only for you.
  • If you forget a word, keep going. Small mistakes are fine.

Speak slower than you think. After every 2 lines, take a small breath.

0 · Before you press Record

Do this once. Then the video stays smooth.

Prep
not on camera
Do not say your password out loud. Type it. Stay silent for 2 seconds.

Ready the app

  • Open DEVORA in Chrome. Dark theme. Zoom 110%.
  • Hide bookmarks. Full screen the browser.
  • Make sure a Kubernetes cluster is already running and active (Kind or Minikube). Creating a cluster live takes too long for LinkedIn.
  • Login page should be visible when you start. Log out if you are already in.

How to talk so it does not sound like a script

  • Look at the screen, not at this paper, when you click.
  • Look at the camera only at the start and the end (if you show your face).
  • You may say “okay”, “so”, “now” — that sounds human.
  • Record 2 takes. Keep the calm one, not the “perfect English” one.

11 · Services · Workloads · Databases · Storage

Fast tour. 20 seconds each. No forms. Only point and talk.

7:50–9:05
1 min 15 sec

Services — 7:50 to 8:10 (20s)

Sidebar → Services. Select namespace demo-app if asked. Point at hello-web.

Services are how other apps reach this app.
ClusterIP is internal. NodePort is reachable from outside.

Workloads — 8:10 to 8:30 (20s)

Sidebar → Workloads. Point at the two or three hello-web pods.

Workloads is the pod view.
If a container is crash looping, you see it here. Not only “pod running”.

Databases — 8:30 to 8:50 (20s)

Sidebar → Databases. Scroll the list. Do not open a long table browser.

If Mongo, Postgres, or MySQL is running in the cluster, this page finds it.
You can browse data from the UI. No CLI.

Storage — 8:50 to 9:05 (15s)

Sidebar → Storage. Point at PVC table.

Storage shows persistent volume claims.
Disks that stay even if the pod restarts.
Databases need this. A website like nginx usually does not.
